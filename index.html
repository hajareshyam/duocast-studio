🚀 How to Deploy to GitHub Pages (2 Minutes)

  1. Create a new GitHub Repository:

    Go to github.com/new and name it (e.g. duocast-studio). Choose Public.

  2. Push these 3 files:

    Upload or git push index.html, style.css, and app.js directly to your repository root.

  3. Enable GitHub Pages:

    Go to your GitHub repo Settings > Pages. Under Build and deployment > Branch, select main (root) and click Save.

  4. You're Live!

    GitHub will give you a free HTTPS link like https://YOUR-USERNAME.github.io/duocast-studio/. Both you and your co-host can open that link anywhere in the world on your phones or laptops!
